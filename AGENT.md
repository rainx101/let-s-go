# AGENT.md

Guidance for any AI agent working on this project.

## Do not assume. Ask me. Question me.

- Do not assume anything. If it is not explicitly stated, treat it as unknown.
- Ask me before acting when anything is unclear or undecided.
- Question me — push back, point out gaps, and confirm intent rather than
  guessing.
- Do not add stacks, libraries, files, config, or features I did not ask for.
- Make the smallest change that answers the actual request. When unsure, stop
  and ask.
